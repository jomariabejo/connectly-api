# Documentation Central

The documentation site for the [Connectly API](../README.md), built with [Docusaurus](https://docusaurus.io/) 3 and deployed on Vercel.

## Local development

```bash
npm install
npm start          # http://localhost:3000, live reload
```

## Build

```bash
npm run build      # static output in build/
npm run serve      # preview the built site
```

`onBrokenLinks` and `onBrokenMarkdownLinks` are both set to `throw`, so **a dead cross-reference fails the build**. That is deliberate — run `npm run build` before pushing.

## Deployment (Vercel)

This site lives in a subdirectory of the `connectly-api` repository, so the Vercel project needs to know where to look.

**First time — link the project:**

1. Import `jomariabejo/connectly-api` in the Vercel dashboard
2. Set **Root Directory** to `documentation-central`
3. Leave the framework preset as detected (Docusaurus) — [`vercel.json`](./vercel.json) already pins the build command and output directory
4. Deploy

After that, every push to `main` redeploys and every pull request gets a preview URL.

**One-off deploy from the CLI:**

```bash
npx vercel --cwd documentation-central          # preview
npx vercel --cwd documentation-central --prod   # production
```

Once the real domain is known, update `url` in [`docusaurus.config.ts`](./docusaurus.config.ts) — only the sitemap and social-card metadata depend on it.

## Structure

```
docs/
├── intro.md                    overview, tech stack, first request
├── getting-started/            installation, configuration (.env reference)
├── api/                        swagger, authentication, users, posts,
│                               comments, likes, pagination, errors
├── architecture/               overview, security, scheduled tasks
├── data-model/                 schema + ERD
├── testing/                    the Mockito suite
└── reference/                  known issues, further reading
```

Section order is set explicitly in [`sidebars.ts`](./sidebars.ts) rather than autogenerated, so the sidebar reads as a path: set up → understand → call → extend.

## Writing

- Mermaid is enabled — use ` ```mermaid ` fences for diagrams
- Prism languages are registered in `docusaurus.config.ts`; add any new one there or it renders unhighlighted
- **Verify claims against a running instance before writing them down.** Several pages document behaviour that contradicts the code's apparent intent; each of those was confirmed with a real request or query first, and the evidence is quoted inline
